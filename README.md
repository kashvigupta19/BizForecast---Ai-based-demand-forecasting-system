# BizForecast

AI-powered sales demand forecasting and inventory management system for small businesses.

## Features
- Demand Forecasting
- Time Series Analysis
- KNN, ANN, CNN Models
- Decision Tree & Random Forest
- Safety Stock Calculation
- Inventory Recommendations
- Interactive Dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- TensorFlow
- Matplotlib
- Seaborn
- Statsmodels


## Project Description
BizForecast predicts future product demand using machine learning and time-series forecasting techniques. It helps small businesses optimize inventory levels, reduce stock shortages, minimize overstocking, and make data-driven decisions through interactive visualizations and forecasting models.
